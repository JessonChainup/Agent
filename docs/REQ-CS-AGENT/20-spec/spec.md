# 客服 Agent 产品需求文档

## 背景

Chainup 商户后台的客服模块目前为纯人工模式，商户运营成本高、响应速度慢。需求引入 AI 客服 Agent，处理常见用户咨询，降低商户人工客服压力，提升响应效率。

## 目标

- 将常见咨询（FAQ/充提/KYC/交易/Gas）的自动回复率提升至 40% 以上
- 用户首次响应时间从"分钟级"降低至"秒级"
- 人工客服仅处理需要人工判断的复杂/资金/合规场景

## 核心指标

| 指标 | 目标值 | 测量方式 | 优先级 |
|:-----|:-------|:---------|:------:|
| 用户满意度 | ≥ 80% | 用户主动标记"满意"的会话数 ÷ 已评价会话总数 | 1（最高）|
| L1 准确率 | ≥ 85% | 用户未标记不满意的 L1 会话数 ÷ L1 总会话数 | 2 |
| 自动回复率 | ≥ 40% | L1 处理的会话数 ÷ 总会话数 | 3 |
| 平均响应时间 | P95 ≤ 5s | 用户输入到 Agent 输出的时间（取 P95 分位数）| 4 |
| 转人工率 | ≤ 60% | L3 会话数 ÷ 总会话数 | 5 |
| 解决率 | ≥ 75% | 未转人工且用户未在会话内再次提出相同问题的会话数 ÷ 总会话数 | 6 |

**指标优先级说明**：当多个指标出现冲突时，按优先级顺序保障。例如：保障用户满意度优先于降低转人工率。
**沉默用户处理**：用户关闭页面未评价的会话——不计入满意度分母，但计入解决率分母且默认为"未解决"。

## 范围

**范围内**：
- FAQ 类常见咨询的自动回复
- 用户账户状态查询（限额/权限/冻结状态）
- 充值与提现状态查询（含链上确认数据）
- KYC 认证进度查询与引导
- 订单状态查询
- 网络 Gas 费用查询
- 商户后台智能客服配置管理
- 上线前评测与上线后监控

**范围外**：
- 涉及资金操作的实际执行（提现审批、转账）——仅查询状态
- 账户的实质冻结/解冻操作——仅生成确认卡片待用户确认
- KYC 资料的实质提交/审核——仅查询状态和引导
- 法币出入金——纯链上资产场景优先
- 跨商户的统一客服管理后台——非本阶段范围
- 多语言翻译——依赖商户原有语言体系
