## M6：评测监控

### 概述

定义客服 Agent 在上线前的评测标准和上线后的持续监控机制，确保 Agent 质量可度量、可追踪、可回退。

### 上线前评测

#### 评测数据集

- **来源**：商户历史客服会话记录（至少 500 条），由商户管理员抽取与脱敏
- **标注要求**：每条会话标注预期行为（L1 直接回复 / L2 确认 / L3 转人工）和期望答案
- **覆盖要求**：六大场景各至少 50 条，含异常场景（超时/未匹配/敏感词）至少 100 条
- **脱敏要求**：用户 ID 替换为脱敏 ID，地址/密码/PIN 替换为占位符

#### 评测指标

| 指标 | 定义 | 合格线 | 优秀线 |
|:-----|:-----|:-------|:-------|
| 准确率 | L1 判断正确的会话数 ÷ L1 总会话数 | ≥ 85% | ≥ 92% |
| L1 率 | L1 处理的会话数 ÷ 总会话数 | ≥ 40%（FAX 场景） | ≥ 55% |
| 升级准确率 | L2→L3 升级决策正确次数 ÷ 升级总次数 | ≥ 80% | ≥ 90% |
| 平均响应时间 | 从输入到输出的时间（秒） | ≤ 3s | ≤ 1.5s |
| 知识库命中率 | 匹配到知识库条目的会话数 ÷ FAQ 类会话数 | ≥ 90% | ≥ 95% |

#### 评测流程

1. **数据集准备**：商户提供标注后的数据集（CSV/JSON 格式）
2. **离线评测**：Agent 对数据集逐条处理，记录响应结果
3. **报告生成**：自动生成评测报告，含各指标达标情况 + 错误案例分类
4. **门禁**：全部指标达合格线方可上线；任一指标低于合格线，返回 Agent 优化
5. **人工复核**：商户运营人员随机抽取 20 条评测结果人工复核，确认准确率可信

### 上线后监控

#### 监控指标

| 指标 | 采集方式 | 告警阈值 | 说明 |
|:-----|:---------|:---------|:-----|
| 全自动准确率 | 会话结束后标记（成功/失败）| < 80% 持续 1h | 用户将 L1 结果标记为"不满意"或触发 L3 申诉 |
| 转人工率 | 会话数统计 | > 50% 持续 2h | 突然异常升高说明模型/知识库有问题 |
| 平均响应时间 | 时间戳差值 | > 8s 持续 5min | 后端或 embedding 性能退化 |
| L3 排队深度 | 队列长度统计 | > 10 持续 3min | 人工客服无法消化涌入量 |
| 知识库命中率 | FAQ 类查询统计 | < 70% 持续 1h | 知识库覆盖率不足或匹配失效 |

#### 监控看板（复用 M5 监控统计页面）

实时展示：处理量趋势、准确率趋势、转人工率趋势、响应时间分布、排队深度。

#### 告警与处理

| 级别 | 触发条件 | 通知对象 | 处理方式 |
|:-----|:---------|:---------|:---------|
| P0 严重 | 准确率 < 60% 或排队 > 50 | 商户管理员 + Chainup 运营 | **立即停用自动回复**，全量转人工 |
| P1 警告 | 准确率 < 80% 持续 > 1h | 商户管理员 | 建议检查知识库或模型 |
| P2 提示 | 转人工率异常升高 > 50% | 商户管理员 | 查看最近会话确认原因 |

**P0 自动停用逻辑**：当准确率跌至 60% 以下连续 5 个监控周期（每个周期 1 分钟），系统自动关闭该商户的自动回复开关，所有**新请求**转人工，允许**已有会话完成当前流程**（优雅退出）。同时发送通知和知识库快照回退信号。

### 灰度发布与回滚策略（新增）

#### 三阶段灰度编排

Agent 上线不允许全量推送，必须分三阶段灰度：

| 阶段 | 范围 | 持续时间 | 退出条件 |
|:-----|:-----|:---------|:---------|
| **Phase 1：影子模式** | 1-2 家灰度商户 | 3-5 天 | 影子对比准确率 ≥ 85% |
| **Phase 2：有限灰度** | 仅 FAQ + 充提场景 | 5-7 天 | 所有指标达合格线 |
| **Phase 3：全量开放** | 所有商户 + 所有场景 | 持续 | 监控正常运行 |

#### Phase 1：影子模式

- **行为**：Agent 并行处理用户请求并生成回复，但回复**不展示给用户**。真实用户看到的仍是人工客服的回复
- **数据积累**：业务指标正常运行，Agent 回答与人工回答做盲测对比
- **退出条件**：影子模式下盲测对比准确率 ≥ 85% 持续 3 天 → 进入 Phase 2
- **如果失败**：盲测准确率 < 75% 持续 2 天 → 退回模型/知识库调优，不进入 Phase 2

#### Phase 2：有限灰度

- **开放场景**：FAQ 查询 + 充提状态查询（高风险场景如 KYC 引导仍走人工）
- **用户比例**：先按 5% 用户开放 → 稳定 1 天 → 20% → 稳定 2 天 → 50% → 稳定 2 天 → 100%
- **对照实验**：同一商户内部分用户走 AI Agent，部分走纯人工（对照组），对比 CSAT 和解决率
- **退出条件**：所有指标达合格线（spec.md 核心指标）持续 5 天 → 进入 Phase 3

#### Phase 3：全量开放

- **行为**：所有场景、所有用户走 AI Agent
- **监控**：P0/P1/P2 告警持续监测
- **回滚能力**：保留 Phase 2 的配置快照，7 天内随时可一键回退到 Phase 2 配置

#### 回滚机制

| 回滚场景 | 触发条件 | 操作 | 影响 |
|:---------|:---------|:-----|:-----|
| 自动回滚 | 全场景下准确率 < 60% 连续 5 个监控周期 | 自动关闭自动回复，全量转人工 | 已有会话优雅退出 |
| 手动回滚 | 商户运营人员观察转人工率异常升高 | 商户管理员在后台一键关闭自动回复 | 5min 内生效 |
| 版本回退 | 新版本知识库更新后指标暴跌 | 回退到上一版知识库 | 知识库 reindex 期间用旧 embedding |
| 场景回退 | 某一场景准确率持续不合格 | 关闭该场景的自动回复 | 仅影响该场景，其他场景正常运行 |

#### 一键回滚开关

- **位置**：M5 商户配置 → 基础开关页
- **触发**：点击"停用自动回复"按钮，二次确认弹窗后生效
- **效果**：自动回复关闭，所有消息转人工，Agent 仅做辅助模式（提供参考回复但不自动展示）
- **恢复**：相同位置点击"重新启用"，走 Phase 2 灰度流程恢复

### 每周质量报告

**cron 定时任务**：每周一 09:00 生成并推送至商户管理员。

报告内容：
- 上周处理总量 {{total}}
- 自动回复率 {{auto_rate}}（△ 相比前一周 {{delta}}）
- 准确率趋势（折线图）
- Top 3 错误类型及根因分析
- 知识库条目缺失 TOP 5（哪些问题频繁命中失败）

### 验收标准

**AC-06-01：离线评测通过门禁**
- Given 商户提交评测数据集
- When 所有指标达标
- Then 评测结果为"通过"
- And Agent 可上线

**AC-06-02：离线评测不通过门禁**
- Given 商户提交评测数据集
- When 准确率 75%（低于 85% 合格线）
- Then 评测结果为"不通过"
- And 输出错误案例 TOP 5 及根因分类
- And 不允许上线

**AC-06-03：P0 优雅停用**
- Given 实时准确率降至 55% 连续 5 个监控周期
- When 监控系统触发 P0
- Then 自动关闭**新请求**的自动回复
- And **已有会话**可继续完成当前流程（COMPLETED 或 ERROR 后不再响应）
- And 通知商户管理员 + Chainup 运营

**AC-06-04：灰度影子模式生效**
- Given Agent 处于 Phase 1（影子模式）
- When 用户发送 FAQ 查询
- Then Agent 并行处理并生成回复
- And 回复不展示给用户
- And 用户仍看到人工客服回复
- And 影子回复存入对比日志

**AC-06-05：灰度比例切换**
- Given Agent 处于 Phase 2
- When 灰度策略从 5% 切换至 20%
- Then 新入会话中 20% 进入 Agent 处理
- And 80% 仍走纯人工
- And 切换在 1 分钟内生效

**AC-06-06：一键回滚**
- Given Agent 处于全量开放（Phase 3）
- When 商户管理员点击"停用自动回复"并确认
- Then 5min 内自动回复关闭
- And 所有消息转人工
- And Agent 仅做辅助模式（参考回复不展示）

**AC-06-07：监控指标实时更新**
- Given 商户打开监控统计页面
- When 有新会话处理完成
- Then 今日处理会话数在 30s 内更新
- And 其它指标按刷新频率更新

**AC-06-08：每周报告自动生成**
- Given 每周一 09:00
- When cron 触发报告生成
- Then 报告通过飞书/邮件推送至商户管理员
- And 包含上周所有监控指标 + 趋势图

### 风险

| 风险 | 影响 | 缓解措施 |
|:-----|:------|:---------|
| 上线前评测数据集与生产环境分布不一致 | 上线后准确率暴跌 | 上线后前 7 天设"观察期"，观察期不自动停用但仍告警 |
| 商户标注质量差（标注错误率高） | 评测结果失真 | 评测报告中的人工复核环节要求商户抽检误标注率 < 5% |
| P0 自动停用误触发（短暂抖动） | 商户业务中断 | 连续 5 个监控周期（5 分钟）才触发，单次抖动不触发 |
