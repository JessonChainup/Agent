## M7：错误处理与审计追溯

### 概述

定义客服 Agent 运行中的错误分类、错误处理策略、审计日志记录、以及数据反馈闭环，确保异常可容错、行为可追溯、Agent 可持续改进。

### 错误分类

| 错误级别 | 严重程度 | 示例 | 影响范围 |
|:---------|:---------|:-----|:---------|
| L1 输入错误 | 低 | 用户输入为空、包含非法字符、语言不支持 | 单次请求 |
| L2 执行错误 | 中 | 内部 API 超时、知识库查询失败、embedding 服务不可用 | 单次请求 |
| L3 关键错误 | 高 | 资金操作执行异常、错误转人工、批量知识库索引失败 | 单商户/局部 |
| L4 灾难错误 | 严重 | 错误执行资金操作、个人数据泄露、全商户 Agent 瘫痪 | 全局/多商户 |

### 错误处理策略

#### L1 输入错误

| 错误类型 | 检测方式 | 处理策略 | 返回内容 |
|:---------|:---------|:---------|:---------|
| 输入为空 | 判空 | 忽略，不处理 | "请输入您的问题" |
| 含非法字符 | 正则检测 | 过滤后如仍有非法字符则拒绝 | "输入内容不合规，请重新描述" |
| 语言不支持 | 语言检测 | 发送默认提示 | "当前支持语言：{language_list}，请使用其中一种语言描述" |
| 超长输入 | 字符数限制（1000 字符）| 截断并按前 1000 字符处理 | 正常返回（用户无感知）|

#### L2 执行错误

| 错误类型 | 重试策略 | 降级策略 | 是否转 L3 |
|:---------|:---------|:---------|:----------|
| 内部 API 超时（5s） | 无重试 | 返回"该信息暂时无法查询" | 否（非紧急）|
| 知识库查询失败 | 重试 1 次（2s 超时） | 返回"知识库暂时不可用" | 否（下次正常重试）|
| embedding 服务不可用 | 重试 1 次（3s 超时） | 返回"智能匹配服务暂时不可用" | 是（新请求才转 L3，当前已有响应的不转）|
| 商户配置读取失败 | 无重试 | 使用系统默认阈值 | 是（记录告警通知商户管理员）|

#### L3 关键错误

| 错误类型 | 重试策略 | 降级策略 | 通知对象 |
|:---------|:---------|:---------|:---------|
| 资金操作 API 返回异常 | 不重试 | 标记为"操作状态未知"→转 L3 人工 | Chainup 运营（即时）|
| 错误将 L1 识别为 L3 | 不重试 | 记录为"误升级"，不降级 | 商户管理员（周报告）|
| 批量知识库索引失败 | 重试 3 次（间隔 30s） | 标记索引为"失败"状态 | Chainup 运营（即时）|
| 评测门禁异常 | 不重试 | 阻止上线 | 商户管理员 + Chainup 运营 |

#### L4 灾难错误

| 错误类型 | 立即动作 | 恢复动作 | 审核要求 |
|:---------|:---------|:---------|:---------|
| 错误执行了资金操作 | 锁定该商户所有 Agent 功能 + 通知 Chainup 风控 | 人工审查操作记录 + 回滚 | 风控 + 产品负责人双签 |
| 个人数据泄露 | 隔离受影响的存储 + 暂停 Agent | 安全团队取证 + 数据清理 | 安全 + 法务双签 |
| 全商户 Agent 瘫痪 | 全局开关关闭（运维执行）| 逐步恢复（灰度 10%→50%→100%）| Chainup 运维负责人 |

### 审计日志

#### 日志记录范围

每一条会话处理记录均写入审计日志，至少包含以下字段：

| 字段 | 类型 | 说明 |
|:-----|:-----|:------|
| `event_id` | string | 全局唯一事件 ID |
| `timestamp` | datetime | 事件发生时间 |
| `merchant_id` | string | 商户 ID |
| `session_id` | string | 会话 ID |
| `user_input` | string | 用户输入（已脱敏）|
| `classification` | string | 场景分类结果 |
| `confidence` | float | 置信度（0-100）|
| `funnel_level` | enum | L1/L2/L3 |
| `action_taken` | string | Agent 执行的操作描述 |
| `api_calls` | array | 调用的内外部 API 列表（含请求/响应摘要）|
| `error_level` | enum/null | 错误级别（无错误则 null）|
| `error_detail` | string/null | 错误详情 |
| `user_satisfied` | boolean/null | 用户是否标记满意（可选）|

#### 日志存储

- **保留期限**：至少 180 天
- **存储位置**：商户独立存储（多租户隔离），Chainup 运营侧可跨商户查询（需权限）
- **脱敏规则**：用户输入中匹配到数字货币地址、邮箱、电话号的字段，存储时替换为 `[REDACTED]`
- **不可篡改**：日志写入后不可修改，仅支持追加

#### 审计查询

- **商户侧**：查询本商户近 180 天内的会话历史，支持按时间/场景/漏斗级别/用户满意度过滤
- **Chainup 运营侧**：跨商户审计查询（需权限审批），支持按错误级别/错误类型聚合统计

### 数据反馈闭环

从审计日志中提取失败案例 → 归因分类 → 触发 Agent 改进。

#### 闭环流程

```
审计日志 → 失败案例提取 → 归因分类 → 改进动作 → 重新评测 → 上线
```

#### 自动归因分类

每天凌晨扫描前 24h 的失败案例，按以下类别归类：

| 失败类别 | 归因 | 自动动作 |
|:---------|:-----|:---------|
| 知识库未覆盖 | 用户问题在知识库中无匹配，但预期应匹配 | 将问题加入"知识库缺失候补列表"，周报告提示 |
| 置信度误判 | 实际应 L1 被判定为 L3（或反之）| 加入"阈值调优观察列表"，累计 10 例同类触发阈值建议 |
| 输入理解错误 | 用户意图被错误分类（如 FAQ 被归为 KYC）| 加入"分类模型优化候选集"，归入下批次训练数据 |
| API 错误 | 内部 API 返回异常 | 触发告警（已在 M6 监控中覆盖）|
| 系统错误 | embedding 超时/配置读取失败 | 自动重试（按 L2 错误策略）|

#### 人工归因

自动归因无法分类的失败案例（占比 < 10%）→ 人工资深运营每周评审一次，补充分类或标记为噪声。

### 验收标准

**AC-07-01：L2 降级不阻塞**
- Given 知识库查询服务不可用
- When 用户发起 FAQ 查询
- Then 返回"知识库暂时不可用"
- And 记录错误日志（错误级别 L2）
- And 不转 L3

**AC-07-02：L3 触发运营通知**
- Given 资金操作 API 返回异常状态码
- When Agent 处理到调用资金操作 API 环节
- Then 立即通知 Chainup 运营（即时通道）
- And 标记该会话为"操作状态未知"

**AC-07-03：审计日志不可篡改**
- Given 审计日志已写入 event_id
- When 尝试修改已写入日志
- Then 写入被拒绝
- And 返回日志不可修改的提示

**AC-07-04：审计日志脱敏**
- Given 用户输入 "我的地址是 1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa"
- When 审计日志写入
- Then 存储为 "我的地址是 [REDACTED]"
- And 原数据不保留

**AC-07-05：多租户隔离**
- Given 商户 A 查看审计日志
- When 查询
- Then 仅返回商户 A 的会话记录
- And 不可跨商户查询

**AC-07-06：自动归因周扫描**
- Given 有一批失败案例
- When 每日凌晨扫描完成
- Then 失败案例按四类归因自动分类
- And 归因结果写入"优化候补列表"

### 风险

| 风险 | 影响 | 缓解措施 |
|:-----|:------|:---------|
| 审计日志存储量过大 | 成本上升 | 设定保留期限 180 天，超期自动归档到冷存储 |
| 脱敏规则遗漏某种格式 | 隐私数据留存 | 脱敏规则每季度审计更新 + 支持正则热更新 |
| 自动归因误归类 | 错误触发改进动作 | 自动归因仅写入"候补列表"，不产生任何执行动作；人工复核后才触发改进 |
| 多次重试仍然失败导致阻塞 | 大量请求堆积 | 重试次数设上限（最多 3 次），超过后外部请求直接进入降级策略 |
