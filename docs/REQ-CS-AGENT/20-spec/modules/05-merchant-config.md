## M5：商户配置

### 概述

定义商户在后台对客服 Agent 的管理界面。商户可控制打开/关闭、配置规则、管理知识库、调整阈值、监控运行状态。

### 配置入口

- **位置**：商户后台 → 增值服务 → 智能客服
- **权限**：仅商户管理员和超级管理员可访问
- **布局**：左导航（5 个配置页）+ 主内容区

### 配置项总览

| 配置页 | 核心内容 | 默认值 |
|:-------|:---------|:-------|
| 基础开关 | 全局启用/停用、自动回复开关 | 关（商户首次需手动启用）|
| 自动回复规则 | 全自动/确认/人工三级阈值 | 系统默认阈值（80%/50%）|
| 知识库管理 | FAQ 条目管理 + 上传/编辑 | 空（商户自行录入）|
| 安全限制 | 高风险操作策略、敏感词过滤 | 强制 L3 |
| 监控统计 | 处理量/准确率/转人工率 看板 | —（只读）|

### 页面一：基础开关

**控件**：

| 控件 | 类型 | 说明 |
|:-----|:-----|:------|
| 全局开关 | 切换开关 | 启用/停用整个客服 Agent 功能 |
| 自动回复开关 | 切换开关 | 关闭后所有消息转人工，Agent 仅做辅助 |
| 客服入口显示设置 | 下拉（标配/精简/隐藏） | 前端入口显示模式 |
| 服务语言 | 多选 | 商户支持的语言列表（默认继承商户设置） |

**全局开关关闭时**：
- 前端不显示客服 Agent 入口
- 所有消息直接进入商户原有客服 Webhook
- 知识库编辑仍可访问

### 页面二：自动回复规则

**控件**：

| 控件 | 类型 | 说明 |
|:-----|:-----|:------|
| 全自动阈值 | 滑块（60%-95%，步长 5%）| L1 自动回复的最低置信度 |
| 确认超时时间 | 输入框（60s-300s）| L2 确认等待时间 |
| 矛盾升级次数 | 输入框（1-5 次）| 客户前后矛盾的升级阈值 |
| 高风险操作模式 | 单选（强制 L3 / 允许 L2 确认）| 资金操作的处理模式 |

### 页面三：知识库管理

**功能列表**：

1. **FAQ 管理**：
   - 列表视图：问题、答案、类别、状态（启用/停用）、最后编辑时间
   - 增删改：录入问题（最多 200 字）+ 答案（富文本，最多 5000 字）+ 类别标签
   - 批量导入：支持 CSV/JSON 格式，最多 500 条/次
   - 版本管理：每次编辑生成快照，可回滚到任意历史版本
2. **文档库**：
   - 上传 PDF/Markdown 文档（每商户总文档数限制 50 个，单文档 ≤ 10MB）
   - 自动切片：文档自动分段并建立 embedding 索引
   - 关联设置：将 Segment 关联到指定类别
3. **搜索测试**：输入测试问题 → 显示 Top 5 匹配结果 + 各匹配分 → 方便商户调优

### 页面四：安全限制

**控件**：

| 控件 | 类型 | 说明 |
|:-----|:-----|:------|
| 敏感词列表 | 文本区（每行一个词）| 命中后直接转 L3 |
| 高风险操作类型 | 多选 | 哪些操作类型禁用 L1/L2（可选：提现/修改限额/账户冻结/API 密钥管理）|
| 日处理上限 | 输入框 | 每日最多自动处理的会话数，超过后全转人工（0=不限制）|
| IP 白名单 | 输入框（CIDR 格式）| 仅白名单 IP 可触发 L1（可选启用）|

### 页面五：监控统计

**只读看板**——数据来自 M6 评测监控模块。

| 指标 | 展示形式 | 刷新频率 |
|:-----|:---------|:---------|
| 今日处理会话数 | 数字卡片 | 实时 |
| 今日自动回复率 | 环形进度图 | 实时 |
| 近 7 天准确率趋势 | 折线图 | 每日更新 |
| 近 7 天转人工率趋势 | 折线图 | 每日更新 |
| 各类别处理量分布 | 柱状图 | 每日更新 |
| 当前队列深度 | 数字（L3 排队数） | 实时 |

### 验收标准

**AC-05-01：全局开关生效**
- Given 商户关闭全局开关
- When 有新用户消息
- Then 消息直接进入原有客服 Webhook
- And 前端不显示客服入口

**AC-05-02：阈值覆盖生效**
- Given 商户设置全自动阈值 90%
- When 某请求置信度 85%
- Then 该请求进入 L2 而非 L1

**AC-05-03：FAQ 增删改生效**
- Given 商户新增 FAQ 条目
- When 用户输入匹配该问题
- Then Agent 使用新创建的 FAQ 回答
- And 旧版 FAQ 不被删除后仍匹配

**AC-05-04：知识库批量导入**
- Given 商户上传 CSV 含 300 条 FAQ
- When 导入完成
- Then 知识库中新增 300 条 FAQ
- And 无效格式行（如空问题）被跳过并记录日志

**AC-05-05：敏感词拦截**
- Given 商户自定义敏感词包含 "退款"
- When 用户消息含 "退款"
- Then 直接转 L3
- And 不经过 L1/L2

**AC-05-06：日处理上限**
- Given 商户设定日处理上限 100 条
- When 当第 101 个会话触发时
- Then 该会话直接转人工
- And 提示"今日智能客服已达服务上限，已为您转接人工客服"

**AC-05-07：搜索测试功能**
- Given 商户输入测试问题 "手续费"
- When 点击搜索测试
- Then 显示 Top 5 匹配条目 + 各匹配分
- And 排序按匹配分降序

### 风险

| 风险 | 影响 | 缓解措施 |
|:-----|:------|:---------|
| 商户误操作关闭自动回复 | 客服压力突然增大 | 关闭时需二次确认弹窗 + 记录变更日志 |
| 知识库版本回滚导致已训练的 embedding 失效 | 匹配准确率下降 | 回滚后触发全量 reindex，过程中用上一版本 embedding |
| 商户敏感词配置过宽泛 | 正常请求被频繁转人工 | 敏感词总字符数限制（最大 1000 字）+ 建议语"过于宽泛的敏感词会影响处理效率" |

### 运营负担评估与开箱模板（新增）

#### 商户维护工时估算

商户运营团队每周的 Agent 维护工时估算（以中小型交易所 5-10 人运营团队为基准）：

| 维护项 | 频次 | 预估工时 | 说明 |
|:-------|:-----|:---------|:------|
| 知识库 FAQ 更新 | 按需（平均每周 3-5 条）| 30-60 分钟/周 | 新增/修改/停用 FAQ 条目 |
| 知识库文档上传 | 首次 2-3 小时，后续按需 | 30 分钟/次 | PDF/Markdown 文档上传并检查切片 |
| 告警处理 | P2 级别每周 1-2 次 | 15 分钟/次 | 查看监控面板、确认原因 |
| 每周质量报告审阅 | 每周 1 次 | 15 分钟 | 阅读周一推送的周报 |
| 阈值调优 | 上线后首月 1-2 次 | 30 分钟/次 | 调整全自动阈值、确认超时等 |
| **合计** | — | **约 2-4 小时/周** | 首次配置额外 4-6 小时 |

#### 开箱即用模板

为降低商户初始配置门槛，Chainup 提供以下预置模板（商户一键导入即可）：

| 模板 | 内容 | 适用商户类型 |
|:-----|:-----|:-------------|
| 标准 FAQ 模板 | 交易所通用 30 条 FAQ（费用/充值/提现/KYC/交易） | 所有商户 |
| 充提引导话术 | 标准充提状态查询 + 异常处理回复模板 | 所有商户 |
| 安全策略模板 | 高风险操作清单 + 默认敏感词列表 + 日处理上限建议值 | 合规要求高的商户 |
| 轻量模板 | 仅 FAQ 场景 + 最低阈值配置，适合评测期商户 | 试用/评测商户 |

#### 上线运营 SOP

**上线前检查清单**（商户管理员执行）：

```
□ 知识库：已导入至少 30 条 FAQ + 覆盖六大场景
□ 阈值配置：已设置全自动阈值（建议 80%）和确认超时（建议 120s）
□ 安全限制：已确认高风险操作清单和敏感词列表
□ 转人工链路：已测试 L3 转人工 → 人工客服收到上下文摘要
□ 通知渠道：告警通知已配置（飞书/邮件）
□ 灰度配置：已选择影子模式或有限灰度
□ 商户培训：至少 1 名运营人员完成 Agent 配置培训
```

**首日护航机制**：
- Agent 上线首 72 小时内，Chainup 平台运营至少 1 人全程在线响应
- 首日每小时检查监控指标（准确率/转人工率/响应时间）
- 如发现指标异常（准确率 < 70% 或转人工率 > 40%），立即评估是否需要降级或回退

**日/周/月运营节奏**：

| 周期 | 动作 | 输出 |
|:-----|:-----|:-----|
| 每日 | 查看监控面板（处理量/准确率/排队深度）| 无（仅在异常时触发告警）|
| 每周 | 阅读质量报告 + 更新知识库 + 检查告警记录 | 周报告已自动推送 |
| 每月 | 商户运营评审（回顾指标趋势 + 计划知识库迭代） | 月度运营摘要 |
