# L1 模块边界：06—评测监控

## 模块职责

实现上线前离线评测门禁、上线后实时监控告警、三阶段灰度发布和回滚机制。

## 输入

- 商户标注数据集（500+ 条，CSV/JSON）
- 实时处理数据（准确率/响应时间/转人工率）
- 灰度配置（Phase 选择）

## 输出

- 评测报告（通过/不通过）
- 监控告警事件（P0/P1/P2）
- 灰度切换事件
- 每周质量报告

## 三阶段灰度

| 阶段 | 行为 |
|:-----|:------|
| Phase 1 影子模式 | Agent 并行处理，回复不展示，盲测对比 |
| Phase 2 有限灰度 | 仅 FAQ + 充提场景，按比例开放（5%→20%→50%→100%）|
| Phase 3 全量开放 | 所有场景、所有用户，保留回滚快照 |

## 监控指标

1. 全自动准确率（< 80% 持续 1h → P1）
2. 转人工率（> 50% 持续 2h → P1）
3. 平均响应时间（> 8s 持续 5min → P1）
4. L3 排队深度（> 10 持续 3min → P1）
5. 知识库命中率（< 70% 持续 1h → P1）

## P0 自动停用

- 准确率 < 60% 连续 5 个监控周期（每个周期 1 分钟）
- 动作：关闭新请求自动回复，允许已有会话优雅退出
- 通知：商户管理员 + Chainup 运营
