# 001：离线评测引擎

## 目标

实现上线前的离线评测功能，读取商户标注数据集（500+ 条），逐条验证后生成评测报告。

## 输入

- 测评数据集文件（CSV/JSON，各场景分布要求见 PRD M6）
- Agent 评测时处理每条的响应结果

## 输出

- 评测报告（5 项指标 + 场景表现 + 错误案例 Top 5）

## 编码范围

```
backend/src/
├── service/
│   └── OfflineEvalService.ts    // 离线评测引擎（调用 Agent 核心逻辑逐条处理）
├── domain/
│   └── EvalReport.ts             // 评测报告实体
```

## 验收标准

| # | AC | 验证方式 | 检查点 |
|:--|:---|:---------|:-------|
| 1 | 通过门禁 | AI-VERIFY | 全部指标达合格线 → 评测通过 |
| 2 | 不通过门禁 | AI-VERIFY | 准确率 75%（< 85%）→ 不通过 + 错误案例 Top 5 |
| 3 | 评测报告生成 | AI-VERIFY | 输出含 5 项指标 + 各场景表现 + 错误案例 |

## Mock 清单

- `MockEvalDataset`：预置各场景标注数据
- `MockAgentProcessor`：模拟 Agent 处理结果

## 不可做

- 不包含自动上线（仅出评测报告，上线需人工确认）
