# L1 模块边界：03—置信度阈值

## 模块职责

实现五因子加权置信度计算，提供商户级阈值微调，支持自动调优。输出的置信度分数是 M2（三级分流）的唯一决策依据。

## 输入

- 用户输入文本
- embedding 匹配结果（从 M4 知识库检索/分类路由获取）
- 操作风险等级（从场景映射获取）
- 历史准确率统计数据

## 输出

- 置信度分数（0-100）
- 分档结果（高/中/低）
- 置信度因子明细（用于审计）

## 置信度计算

```
总分 = 语义匹配度 × 35% + 意图清晰度 × 25% + 上下文连续性 × 15% + 操作风险等级 × 15% + 历史准确率 × 10%
```

各因子范围 0-100，总分范围 0-100。

分档：
- 高：≥ 80%（L1 全自动）
- 中：50%-79%（L2 确认）
- 低：< 50%（L3 人工）
- 高风险关键词 → 强制 L3（跳过计算）

## 商户配置

| 参数 | 类型 | 默认值 | 范围 |
|:-----|:-----|:-------|:-----|
| 全自动阈值 | int | 80 | 60-95 |
| 确认超时(ms) | int | 120000 | 60000-300000 |
| 矛盾升级次数 | int | 2 | 1-5 |
| 高风险强制L3 | boolean | true | true/false |

## 自动调优

连续 50 次同类问题准确率 > 95% → 该问题阈值下调至 75%（不 < 60% 兜底）。

## 错误码段

- 2301：置信度计算异常（因子缺失）
- 2302：商户配置读取失败

## 依赖

- 无（独立模块，供 M2 调用）
