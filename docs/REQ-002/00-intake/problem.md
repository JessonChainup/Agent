# REQ-002: Google / Apple 社交登录集成 — Problem

## 背景

Chainup SaaS 交易所的终端用户目前仅支持邮箱/手机号注册和登录。缺乏第三方社交登录（Google、Apple）导致：

1. **注册转化率低**：新用户需填写邮箱、验证、设置密码，流程较长，放弃率高
2. **老用户找回成本高**：忘记密码后通过邮件/短信重置流程复杂
3. **竞品差距**：主流 CEX（Binance、OKX、Bybit）均已支持 Google/Apple 登录
4. **移动端体验割裂**：iOS/Android 上用户期望一键登录而非手动输凭证

## 业务目标

1. 降低注册摩擦，提升注册转化率 +15%（参考行业数据：社交登录平均提升 20-30%）
2. 缩短登录耗时，减少密码找回场景（目标：登录页面平均完成时间缩短 40%）
3. 与主流 CEX 对齐基础体验，消除竞品差距

## 核心用户故事

| 用户 | 场景 | 价值 |
|------|------|------|
| 新用户 Alice | 通过 Google 一键注册并登录交易所 | 3 步完成开账户，无需填写邮箱/密码 |
| 新用户 Bob | 通过 Apple ID 注册登录（iOS 场景） | 符合 iOS 用户习惯，体验原生 |
| 老用户 Carol | 已有邮箱账户，今天在 App 上用 Google 登录，系统提示可关联该 Google 账号 | 不用记密码，后续都能用 Google 登录 |
| 老用户 Dave | 已有账户，在 Web 端点击 Apple 登录并关联 | 跨端统一体验 |

## 非目标

- 不涉及其他社交登录（Facebook、Twitter、WeChat 等）—— 如有需要可后续扩展
- 不涉及 OAuth 登录后的风控/AML 策略调整（仅登录入口变更，KYC 流程位置不变）
- 不涉及手续费/交易功能本身的变化
